Debug Tools

Maintenance actions for the local database and RAWG cache.

Force fresh data

Clears the cached RAWG responses and marks every stored game stale, so the next time you open a page the data is re-fetched fresh from the API. Your list, ratings, and feedback are kept.

Reset database

Destructive. Deletes your entire library — all entries, games, recommendation feedback, and cache. This cannot be undone. Consider exporting a backup first (download JSON backup).
