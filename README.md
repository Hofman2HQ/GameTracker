# Game Catalog

A .NET MAUI application for managing your game collection, built with modern technologies and best practices.

## Features

- Game catalog management
- RAWG API integration for game information
- User authentication
- Local storage with SQLite
- Cross-platform support (Windows, Android, iOS, macOS)

## Prerequisites

- .NET 8.0 SDK or later
- Visual Studio 2022 or later with .NET MAUI workload
- RAWG API key (optional, a default key is provided)

## Setup

1. Clone the repository
2. Open the solution in Visual Studio
3. Restore NuGet packages
4. Build the solution

## Running the Application

### Windows
1. Set the startup project to `MyGameCatalog`
2. Select "Windows Machine" as the target
3. Press F5 or click "Start"

### Android
1. Set the startup project to `MyGameCatalog`
2. Select an Android device or emulator
3. Press F5 or click "Start"

### iOS
1. Set the startup project to `MyGameCatalog`
2. Select an iOS device or simulator
3. Press F5 or click "Start"

## Configuration

The application uses a configuration file to store settings. The default configuration includes:

- RAWG API key
- Firebase configuration
- User preferences
